# 🎭 Playwright Testes - Projeto de Estudo

Projeto de automação de testes com Playwright + TypeScript, criado para demonstrar habilidades em testes end-to-end.

## 🚀 Tecnologias
- Playwright
- TypeScript
- GitHub Actions (CI/CD)

## 📁 Estrutura
- `pages/` → Page Objects (Inventory, Cart, Checkout)
- `fixtures/` → Fixture de login
- `tests/` → Testes (login, carrinho, checkout)

## ▶️ Como rodar
```bash
npm install
npx playwright test
